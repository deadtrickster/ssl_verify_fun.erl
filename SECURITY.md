# Security Policy

## Supported versions

Only the latest release on [Hex](https://hex.pm/packages/ssl_verify_fun) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.
Report it privately through
[GitHub Security Advisories](https://github.com/deadtrickster/ssl_verify_fun.erl/security/advisories/new)
or to the [EEF CVE Numbering Authority](https://cna.erlef.org/).
